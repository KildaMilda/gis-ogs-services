# Карточка проекта

## 1. Паспорт проекта
- **Название проекта:** Сервер публикации открытых геоданных по стандартам OGC (WMS и WFS) на базе GeoServer
- **Трек:** ГИС/ДЗЗ и космические ИТ (блок E — Веб-ГИС и визуализация)
- **Тема из каталога:** № 38 — «Публикация OGC-сервисов. WMS и WFS»
- **Формат выполнения:** индивидуальная работа (1 участник)
- **Участник:** Аверин Артём Артурович, группа 648
- **Куратор:** [ФИО преподавателя]
- **Репозиторий:** https://github.com/KildaMilda/gis-ogs-services
- **Сроки:** промежуточная демонстрация на хакатоне — ~7 декабря, итоговая сдача — до 12 декабря

## 2. Суть работы в двух словах
На базе GeoServer разворачивается картографический сервер с открытыми данными по микрорайону Дашково-Песочня (г. Рязань, Октябрьский район): здания, дорожная сеть и остановки общественного транспорта. Слои публикуются по протоколам **WMS** и **WFS**, проверяются через `GetCapabilities` и подключаются к простому веб-клиенту на Leaflet (а также к настольному QGIS).

## 3. Стек и исходные данные
- **Данные:** OpenStreetMap (лицензия ODbL), формат GeoPackage (`.gpkg`), системы координат EPSG:4326 и EPSG:3857.
- **Инструменты:** QGIS (подготовка слоёв и проверка подключения), GeoServer + Docker (публикация сервисов), Leaflet / HTML + JS (веб-клиент), Git + GitHub (хранение кода и документации).
